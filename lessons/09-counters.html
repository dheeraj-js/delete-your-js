Lesson 09 / 17 · 🔢 CSS counters

CSS can count. Really.

"3 toppings selected" is a number that changes as you click. Surely that needs JavaScript? Nope. CSS has had counters for years, and they can count ticked boxes.

Replaces: change listeners · querySelectorAll(':checked').length · textContent updates Uses: counter-reset · counter-increment · counter() ✅ Every browser (it's very old!)

1 In plain English

🤔

What are we building?A live "X selected" counter

Tick pizza toppings and a label shows how many you've picked, updating instantly.

🧮

😓 The old waySomeone counts heads every time

Every time a box changes, JS runs over, counts all the ticked boxes again, and writes the new number on the label.

🎟️

😎 The new wayA clicker counter at the door

CSS keeps a counter. Each ticked box clicks it up by one. The label at the end shows the total.

🧐 What this code does, step by step

  1. JS puts a listener on every checkbox.
  2. When any of them changes, JS finds all the ticked ones (:checked) and counts them (.length).
  3. It writes the number into the label with textContent.
  4. No CSS needed for the counting, but 4 listeners and a recount on every click.

🧐 What this code does, step by step

  1. counter-reset: picked creates a counter called picked, starting at 0, for this box.
  2. .new-topping:checked = "each ticked box". counter-increment adds 1 for each one.
  3. CSS counts in reading order (top to bottom), so the label at the end sees the final total.
  4. ::after is a ghost element 👻. Its content prints the number with counter(picked) plus our text.

4 Good to know

📖

The classic use: automatic numbering. Chapters, steps, figures. All the numbered steps on this site are CSS counters.

⚠️

Limits: the number only exists for display. You can't send it to a server or use it in maths. If you need the number for logic, that's a real JS job.

🔢

Styles: counter(picked, upper-roman) gives I, II, III. lower-alpha gives a, b, c. You can even make your own with @counter-style.

💡 If a number is just for showing, CSS can probably count it for you.
