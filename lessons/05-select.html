Lesson 05 / 17 · 🍕 Customizable select

Pretty select boxes that are still real selects

Designers always want the dropdown to look custom: icons, colours, rounded corners. For 25 years the answer was "rebuild it in JavaScript". Now you can style the real thing.

Replaces: Select2 · Choices.js · hand-made fake dropdowns Uses: appearance: base-select · ::picker(select) · <selectedcontent> ⚠️ Chrome/Edge 135+ only (Sept 2026). Other browsers show a normal select, which still works

1 In plain English

🤔

What are we building?A "pick one" dropdown with icons

Like choosing a country, a size, or in our case, dinner. 🍕🍔🌮

🎭

😓 The old wayHide the real one, build a costume

You couldn't style <select>, so people hid it and built a fake one out of divs. Then they rebuilt keyboard support, screen reader support, mobile... badly.

👗

😎 The new wayDress up the real thing

One line, appearance: base-select, tells the browser: "let me style this properly". It's still a real select, so everything keeps working.

⚠️

Your browser doesn't support customizable selects yet, so you'll see a normal dropdown on the green side. That's the point: it still works for everyone. Open this page in Chrome or Edge to see the styled version.

🧐 What this code does, step by step

  1. We build a fake select: a button that shows the choice, and a list that opens below it.
  2. Click the button: JS toggles the is-open sticker on the list.
  3. Click an option: JS copies its text into the button, moves the "selected" sticker, and closes the list.
  4. Click outside: JS closes it (sound familiar? same as Lesson 01).
  5. The big problem: it's not a real form field. No arrow keys, no screen reader, and it doesn't send a value when a form is submitted. Libraries fix this with 60KB+ of code.

🧐 What this code does, step by step

  1. It's a normal <select> with normal <option>s, so forms, keyboard and screen readers just work.
  2. New: we can put HTML inside options (like the emoji <span>).
  3. <selectedcontent> means "copy the chosen option here". That's the job JS did with innerHTML.
  4. appearance: base-select is the switch that unlocks styling. ::picker(select) is the drop-down panel.
  5. :open is a new mood 😊: "when the select is open", so the arrow can flip.
  6. Old browser? It ignores the new parts and shows a normal select. Nothing breaks. 🪜

4 Good to know

🧪

This is the newest feature in the talk. Chrome and Edge have it; other browsers are working on it. Because it falls back to a normal select, you can use it today as a bonus.

📱

On phones, a real select can open the phone's own picker, which a fake one never can.

💡 Stop rebuilding form fields in JavaScript. Style the real ones.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

<select>🧱 HTML tag
A dropdown list to pick one choice from.Like: a menu at a restaurant
<option>🧱 HTML tag
One choice inside a select.Like: one dish on the menu
<selectedcontent>🧱 HTML tag
Shows a copy of the chosen option inside the closed select button, pictures and all.Like: a photo of the dish you ordered
appearance🔧 Property
Switches the browser's built-in look. appearance: base-select unlocks a select you can fully style.Like: taking the cover off so you can repaint it
::picker()👻 Pseudo-element: a "ghost" part
::picker(select) is the pop-up list of a select. Now you can style it.Like: the menu the waiter hands you
::picker-icon👻 Pseudo-element: a "ghost" part
The little ▾ arrow on a select.Like: the arrow on a drawer handle
:open😊 Pseudo-class: a "mood"
When a select, details or dialog is open.Like: a door that is open
:checked😊 Pseudo-class: a "mood"
When a checkbox or radio button is ticked, or a select option is chosen.Like: a light switch in the ON position
name⚙️ HTML attribute
A group name. On <details>: the same name means only one can be open at a time. On form fields: the label used when the form is sent.Like: a team name
rotate🔧 Property
Turns an element, e.g. rotate: 180deg flips an arrow upside down.Like: turning a steering wheel
deg📏 Unit
Degrees, for turning. 180deg = half a turn, 360deg = a full turn.Like: a compass
position🔧 Property
How a box is placed: static (normal), relative, absolute (exact spot inside a positioned parent), fixed (stuck to the screen), sticky.Like: pinning a note to the board
top / right / bottom / left🔧 Property
Used with position: how far from each edge the box sits.Like: "2 cm from the top of the page"
z-index🔧 Property
Which box is on top when boxes overlap. The bigger number is closer to you.Like: a stack of paper
margin-top🔧 Property
Space outside the box, on the top side only.Like: a gap above you in the queue
padding🔧 Property
Space INSIDE the border, between the edge and the content.Like: bubble wrap inside a box
border🔧 Property
A line around the box: thickness, style and colour, e.g. 1px solid grey.Like: a picture frame
border-radius🔧 Property
Rounds the corners. Bigger number = rounder.Like: sanding the corners of a table
box-shadow🔧 Property
A shadow around the box: sideways, down, blur and colour.Like: the shadow under a floating card
font-weight🔧 Property
How bold the text is: 400 = normal, 700 = bold.Like: pressing harder with a pen
background🔧 Property
The colour or picture behind the element.Like: wallpaper
transition🔧 Property
Animate smoothly when a value changes, instead of jumping.Like: a dimmer switch instead of an on/off switch
calc()🧮 Function
Does maths with mixed units, e.g. calc(100% - 2rem).Like: a calculator
rgb()🧮 Function
A colour from red, green and blue amounts. rgb(0 0 0 / .5) = half see-through black.Like: mixing three paints
rem📏 Unit
Relative to the page's base text size (usually 16px). 2rem = twice that. Grows if the user picks bigger text.Like: "two handfuls": depends on the hand
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
<ul> / <li>🧱 HTML tag
A list (ul) and each item in it (li).Like: a shopping list and its lines
<span>🧱 HTML tag
A plain wrapper for a bit of text inside a line.Like: a highlighter pen
