Lesson 01 / 17 · 📋 Popover

Dropdown menus with zero JavaScript

Menus that open, close when you click somewhere else, close on Escape, and sit on top of everything. It used to take a pile of JS. Now it's one HTML attribute.

Replaces: click listeners · "click outside" code · Escape key code · z-index fights Uses: popover · popovertarget ✅ All modern browsers (Baseline 2024)

1 In plain English

🤔

What are we building?A button that opens a little menu

Like the "⋮" or "Menu" button on almost every website. Click it and a list drops down.

🧑‍🔧

😓 The old wayHire an electrician for every light

With JavaScript, we wire everything by hand: "when clicked, show it", "when clicked outside, hide it", "when Escape is pressed, hide it". Forget one wire and it breaks.

💡

😎 The new wayThe light switch comes built in

We tell the browser: "this button controls that menu". The browser already knows how opening, closing, Escape and clicking outside should work.

🧐 What this code does, step by step

  1. CSS hides the menu (display: none) and has one rule: "if the menu has the is-open sticker, show it".
  2. JS finds the button and the menu on the page (querySelector = "go and find").
  3. Doorbell #1: when the button is clicked, JS adds or removes the is-open sticker.
  4. Doorbell #2: when you click anywhere else on the page, JS removes the sticker.
  5. Doorbell #3: when you press Escape, JS removes the sticker and puts focus back on the button.
  6. JS also has to update aria-expanded by hand so screen readers know if it's open. Forget this and blind users are lost.

🧐 What this code does, step by step

  1. popover on the list tells the browser: "this is a pop-up thing, hide it until asked".
  2. popovertarget="new-menu" on the button says: "I control the thing called new-menu". Click = toggle.
  3. That's it. The browser now handles click outside ("light dismiss"), Escape, and putting focus back.
  4. It goes in the top layer 🥞, so it's always on top. No more z-index: 999999.
  5. The browser also tells screen readers whether it's open (aria-expanded) automatically.
  6. The CSS is only there to place the menu under the button.

  3. ✅Click outside, Escape and screen readers all handled

4 Good to know

🎛️

popover="auto" (the default) closes other popovers and closes on click outside. popover="manual" stays open until you close it: good for toasts.

🎁

You can also use popovertargetaction="show" or "hide" for buttons that only open or only close.

🔍

You can style the open state with the :popover-open mood, and animate it (Lesson 12 shows how).

💡 One attribute replaced 24 lines of JavaScript, and the result is more accessible.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

popover⚙️ HTML attribute
Turns an element into a pop-up that starts hidden, shows on the top layer, and closes on Esc or a click outside.Like: a jack-in-the-box
popovertarget⚙️ HTML attribute
On a button: clicking it opens and closes the popover with that id.Like: a remote paired with one TV
id⚙️ HTML attribute
A unique name for ONE element. Buttons, labels and links point at it.Like: a house number
class⚙️ HTML attribute
Name-tags for an element so CSS and JS can find it. One element can wear several.Like: stickers on a lunchbox
href⚙️ HTML attribute
Where a link goes. href="#faq" jumps to the element with id faq.Like: the address on a signpost
position🔧 Property
How a box is placed: static (normal), relative, absolute (exact spot inside a positioned parent), fixed (stuck to the screen), sticky.Like: pinning a note to the board
top / left🔧 Property
Used with position: how far from the top and left edges the box sits.Like: "2 cm from the top, 1 cm from the left"
z-index🔧 Property
Which box is on top when boxes overlap. The bigger number is closer to you.Like: a stack of paper
display🔧 Property
How a box behaves: block (own line), inline (inside text), flex or grid (arranges its children), none (hidden).Like: choosing furniture layout for a room
margin🔧 Property
Space OUTSIDE the border, pushing other things away.Like: personal space
inset🔧 Property
A shortcut for top, right, bottom and left in one go. inset: 0 = stretch to all four edges.Like: wall-to-wall carpet
anchor-name🔧 Property
Gives an element a name so other elements can be placed next to it.Like: dropping a pin on a map
position-anchor🔧 Property
Says which anchor (by name) this element should stick to.Like: "follow that pin"
anchor()🧮 Function
Reads a position from the anchor. top: anchor(bottom) = "start where the button ends".Like: "stand just below the flag"
calc()🧮 Function
Does maths with mixed units, e.g. calc(100% - 2rem).Like: a calculator
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
<ul> / <li>🧱 HTML tag
A list (ul) and each item in it (li).Like: a shopping list and its lines
<a>🧱 HTML tag
A link. Its href says where it goes.Like: a signpost
