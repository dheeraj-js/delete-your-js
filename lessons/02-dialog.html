Lesson 02 / 17 · 🪟 Dialog

Modal pop-ups without a modal library

A box that appears in the middle of the screen, darkens everything behind it, and won't let you click the page until you close it. HTML has a tag for exactly this.

Replaces: overlay divs · focus handling · Escape key · scroll locking Uses: <dialog> · commandfor · ::backdrop · :has() ✅ <dialog>: all browsers · 🆕 commandfor: newly available (2025)

1 In plain English

🤔

What are we building?A "Are you sure?" pop-up

Cookie banners, login boxes, "delete this?" questions. They sit on top and everything behind goes dark.

🎭

😓 The old wayBuild a fake stage out of cardboard

We made a big dark div to cover the page, put our box on it, then wrote JS to stop scrolling, move the keyboard focus, and listen for Escape.

🏛️

😎 The new wayUse the theatre's real stage

The browser has a real modal built in: <dialog>. It has its own dark curtain (::backdrop) and handles focus and Escape itself.

🧐 What this code does, step by step

  1. A giant dark div covers the whole screen (position: fixed; inset: 0). It's hidden until JS adds is-open.
  2. openModal: add the sticker, freeze page scrolling, move keyboard focus into the box.
  3. closeModal: remove the sticker, unfreeze scrolling, send focus back to the button.
  4. Extra doorbells for clicking the dark area and pressing Escape.
  5. Bug: press Tab a few times while it's open. Focus escapes to the page behind! Fixing that ("focus trap") is another ~20 lines.

🧐 What this code does, step by step

  1. <dialog> is a real modal box built into HTML. It's hidden until opened.
  2. commandfor="new-modal" = "this button controls new-modal". command="show-modal" = "open it as a modal".
  3. When open, the browser puts it in the top layer 🥞, makes the page behind unclickable, and keeps Tab inside.
  4. Escape closes it. closedby="any" also closes it when you click the dark area.
  5. ::backdrop is the free dark curtain. We only choose its colour.
  6. html:has(#new-modal[open]) means "if the page has an open modal, stop scrolling". No JS needed.

4 Good to know

🧾

Closing with a form: <form method="dialog"><button>Close</button></form> inside a dialog closes it in every browser, even old ones.

🆕

commandfor/command (the "invoker" buttons) are newly available. For older browsers, one line of JS does the same job: dialog.showModal(). closedby is newer still. Without it, Escape still works.

🍞

Want a pop-up that does not block the page (like a toast)? Use a popover (Lesson 01). Use <dialog> when the user must deal with it first.

💡 Stop building fake modals. HTML has a real one, and it gets focus right, which most hand-made ones don't.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

<dialog>🧱 HTML tag
A built-in pop-up window. As a modal it blocks the page behind, Esc closes it and focus moves inside.Like: a pop-up booth with its own door
commandfor⚙️ HTML attribute
On a button: which element (by id) this button controls.Like: "this remote is for the bedroom TV"
command⚙️ HTML attribute
What the button does to that element, e.g. show-modal, close or toggle-popover.Like: which button you press on the remote
closedby⚙️ HTML attribute
How a dialog may be closed: any (Esc or click outside), closerequest (Esc only) or none.Like: house rules for leaving
role⚙️ HTML attribute
Tells screen readers what something is (e.g. dialog, tooltip) when the tag doesn't say it already.Like: a job-title badge
aria-modal⚙️ HTML attribute
Tells screen readers "only this window matters right now".Like: a "meeting in progress" sign
::backdrop👻 Pseudo-element: a "ghost" part
The full-screen layer behind a modal dialog or popover. Style it to dim or blur the page.Like: dimming the room lights
:has()😊 Pseudo-class: a "mood"
"Has something inside that matches". Lets a parent change because of its child. The famous "parent selector".Like: "any box that has a cat in it"
html👉 Selector
The html element: the whole page, the outermost box.Like: the whole house
display🔧 Property
How a box behaves: block (own line), inline (inside text), flex or grid (arranges its children), none (hidden).Like: choosing furniture layout for a room
position🔧 Property
How a box is placed: static (normal), relative, absolute (exact spot inside a positioned parent), fixed (stuck to the screen), sticky.Like: pinning a note to the board
inset🔧 Property
A shortcut for top, right, bottom and left in one go. inset: 0 = stretch to all four edges.Like: wall-to-wall carpet
z-index🔧 Property
Which box is on top when boxes overlap. The bigger number is closer to you.Like: a stack of paper
place-items🔧 Property
Where children sit inside a grid. place-items: center puts them in the middle.Like: centring a picture on the wall
background🔧 Property
The colour or picture behind the element.Like: wallpaper
backdrop-filter🔧 Property
Blurs or tints whatever is BEHIND the element.Like: frosted glass
blur()🧮 Function
How blurry: blur(6px) is a soft frosted look.Like: squinting
rgb()🧮 Function
A colour from red, green and blue amounts. rgb(0 0 0 / .5) = half see-through black.Like: mixing three paints
overflow🔧 Property
What to do with content too big for its box: visible (spill out), hidden (cut off), auto (scrollbars when needed).Like: a suitcase that is too full
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
<h3>🧱 HTML tag
A heading. h1 is the biggest, h6 the smallest.Like: a chapter title
