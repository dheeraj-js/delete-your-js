Lesson 11 / 17 · 📦 Container queries

Components that fit wherever you put them

A card in a wide area should sit side by side. The same card in a narrow sidebar should stack. Media queries only know the window size. Container queries know the box size.

Replaces: ResizeObserver · "is-wide" classes · duplicate components per layout Uses: container-type · @container · cqi units ✅ All modern browsers (Baseline 2023)

1 In plain English

🤔

What are we building?A card that rearranges itself

Plenty of space? Picture on the left, text on the right. Squeezed? Picture on top, text below.

🧑‍🔧📏

😓 The old wayA person with a tape measure

JS uses a ResizeObserver (a tape measure that watches a box) and adds an is-wide sticker when the box gets big enough.

🛋️

😎 The new wayFurniture that fits the room

A sofa doesn't care how big the house is. It cares how big the room is. @container lets a component ask "how big is my room?"

🪟 Media query asks: "how big is the WINDOW?"

The whole screen is wide, so every card thinks it has room, even the one squashed in the narrow sidebar. 😬

📦 Container query asks: "how big is MY BOX?"

Each card checks its own box. The sidebar card stacks and the main card goes wide. 😎

🧐 What this code does, step by step

  1. ResizeObserver is a tape measure 📏 that JS attaches to a box. It reports every time the box changes size.
  2. Each time, JS reads the width and asks "is it more than 420px?"
  3. If yes, it adds the is-wide sticker. CSS then puts the picture and text side by side.
  4. On slow phones the card can show the wrong layout for a moment before JS runs.

🧐 What this code does, step by step

  1. container-type: inline-size turns the wrapper into a room 🏠 whose width its children can check.
  2. @container (width > 420px) means "if my room is wider than 420px, use these styles". It works like a media query, but for the box.
  3. Inside, we switch the card to two columns: picture left, text right.
  4. 6cqi = "6% of the room's width". The title grows and shrinks with the box. clamp() sets a minimum and maximum size.

4 Good to know

♻️

Why teams love it: build a component once and drop it into a sidebar, a grid or a full-width area. It adapts on its own. No more "card-small" and "card-large" versions.

🏷️

Name your rooms when you have several: container-name: sidebar, then @container sidebar (width > 300px).

🪟

Media queries are still right for page-level layout (e.g. "hide the sidebar on phones"). Container queries are for components.

💡 Components should care about the room they're in, not the size of the whole house.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

container-type🔧 Property
container-type: inline-size makes a box a "container", so its children can react to ITS width.Like: giving a room its own thermostat
@container📜 @-rule
Rules that apply when a container box is a certain size. Like @media, but for a box, not the screen.Like: "if the room is small, stack the chairs"
cqi📏 Unit
1% of the container's width. Text sized in cqi grows with its box, not the screen.Like: a slice of your own box
display🔧 Property
How a box behaves: block (own line), inline (inside text), flex or grid (arranges its children), none (hidden).Like: choosing furniture layout for a room
grid-template-columns🔧 Property
The columns of a grid. 1fr 2fr = two columns, the second twice as wide.Like: drawing columns on a table
fr📏 Unit
A fraction of the free space in a grid. 1fr 2fr = two columns, the second twice as wide.Like: sharing pizza slices
align-items🔧 Property
Lines children up (usually up and down) inside a flex or grid row: start, center, end.Like: lining people up by height
font-size🔧 Property
How big the text is.Like: the size of the letters
clamp()🧮 Function
clamp(smallest, preferred, biggest): grows with the screen but never goes past the limits.Like: a belt with a smallest and biggest hole
rem📏 Unit
Relative to the page's base text size (usually 16px). 2rem = twice that. Grows if the user picks bigger text.Like: "two handfuls": depends on the hand
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
<h3>🧱 HTML tag
A heading. h1 is the biggest, h6 the smallest.Like: a chapter title
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
