Lesson 17 / 17 · 🎬 View transitions

App-like page transitions on a normal website

You've been watching this all along: every time you clicked "Next", the page faded and slid, the title morphed, and the top bar stayed still. These are normal, separate HTML pages, and the effect is pure CSS.

Replaces: SPA routers (just for animations) · Barba.js / Swup · fetch + innerHTML swapping Uses: @view-transition · view-transition-name 🆕 Chrome/Edge 126+, Safari 18.2+. Firefox: same-page only so far (check caniuse)

1 In plain English

🤔

What are we building?Smooth animations between pages

Click a link and, instead of a hard white flash, the old page fades out, the new one fades in, and matching things morph from one to the other.

🧳

😓 The old wayNever actually leave the room

To animate between pages, sites stopped real navigation. JS downloaded the next page, swapped the content by hand, faked the URL, and animated it. That's basically a whole app framework (a big ready-made JavaScript toolkit, like React).

📸

😎 The new wayThe browser takes before and after photos

The browser takes a photo of the old page and a photo of the new page, then cross-fades between them. Give two things the same view-transition-name and it morphs one into the other.

view-transition-name: donut

🧐 What this code does, step by step

  1. Stops every link from working normally (preventDefault).
  2. Fades the current page out and waits for the fade to finish.
  3. Downloads the next page in the background (fetch) and reads it.
  4. Replaces the current page's content with the new content, and changes the title.
  5. Fakes the URL with history.pushState so the address bar looks right.
  6. Now the back button, scroll position and screen readers are all broken, and each needs more code.

🧐 What this code does, step by step

  1. @view-transition { navigation: auto; } on both pages = "please animate between my pages". That alone gives a smooth cross-fade.
  2. The browser takes a 📸 photo of the old page, loads the new page normally, takes a 📸 of it, and blends between them.
  3. view-transition-name gives an element a name tag. If the old and new page both have something called donut, the browser morphs its size and position.
  4. It's still a real page load: real URL, back button, scroll, screen readers. Nothing to fake.
  5. ::view-transition-old/new let you pick your own animation. This site uses a small slide up.
🖥️

Presenter tip: page transitions only work over http://, not when opening files directly (file://). Run the site with VS Code Live Server or npx serve (see README).

4 Good to know

🪜

Browsers without support simply do a normal page load. Zero risk.

⚛️

Single-page apps (React, Vue) use the same feature via document.startViewTransition(), one JS call that replaces a lot of animation-library code.

🏷️

Each view-transition-name must be unique on a page. Two elements with the same name on one page = no transition.

💡 Multi-page websites can feel like apps now, with one line of CSS.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

@view-transition📜 @-rule
@view-transition { navigation: auto; } on both pages means "animate when I go from one page to the other".Like: a smooth scene change in a film
view-transition-name🔧 Property
A name tag. An element with the same name on the old and new page morphs from one to the other.Like: the same actor in two scenes
::view-transition-old()👻 Pseudo-element: a "ghost" part
A snapshot of the OLD page (or named element) while it changes. Give it your own leaving animation.Like: the "before" photo
::view-transition-new()👻 Pseudo-element: a "ghost" part
A snapshot of the NEW page (or named element) while it changes. Give it your own arriving animation.Like: the "after" photo
animation🔧 Property
Plays a @keyframes animation: its name, how long, how many times.Like: pressing play on a flip-book
@keyframes📜 @-rule
A named animation: the steps from start (from / 0%) to end (to / 100%).Like: the pages of a flip-book
ease-in / ease-out🎚️ Value
Speed curves. ease-in starts slow and speeds up, ease-out starts fast and slows down at the end.Like: a car pulling away / parking
s / ms📏 Unit
Seconds and milliseconds, for timings. 1000ms = 1s, so .3s = 300ms.Like: a stopwatch
