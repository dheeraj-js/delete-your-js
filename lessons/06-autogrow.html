Lesson 06 / 17 · 📝 field-sizing

Text boxes that grow as you type

A message box that starts small and grows with your text, like in chat apps. It used to need JavaScript on every key press. Now it's one CSS line.

Replaces: input listeners · scrollHeight measuring · hidden "measuring" spans Uses: field-sizing: content 🆕 Newly available in all browsers (June 2026)

1 In plain English

🤔

What are we building?A box that fits its words

Type more lines and the box gets taller. Delete them and it shrinks. No ugly scrollbar inside.

📏

😓 The old wayMeasure after every single letter

After every key press, JS squashes the box, measures how tall the text is, and sets the height. Type 100 letters, measure 100 times.

🎈

😎 The new wayA balloon that fills with air

field-sizing: content says "be as big as what's inside you". The box stretches like a balloon on its own.

2 Before vs after: type a few lines in each

⚠️

Your browser doesn't support field-sizing yet. The green boxes will stay a fixed size. Update your browser to see it grow.

😓

BEFORE · JavaScript

Measure on every key press

🏷️ Tag:
7lines of JavaScript
1×per key press
😩input width needs more JS

🧐 What this code does, step by step

  1. JS listens for input, which fires every time you type or delete a character.
  2. It sets the height to auto first, so the box can also shrink when you delete text.
  3. Then it reads scrollHeight ("how tall is ALL the text, including the hidden part?") and uses that as the height.
  4. The one-line tag box doesn't grow at all. Making an input grow sideways needs even more JS (people copy the text into a hidden span to measure its width!).
😎

AFTER · CSS

One property

🏷️ Tag:
0lines of JavaScript
1line of CSS
↔️↕️grows both ways

🧐 What this code does, step by step

  1. field-sizing: content means "make this box the size of the text inside it". That's the whole feature.
  2. min-block-size: 3lh = "at least 3 lines high". lh is a unit meaning "one line of text".
  3. max-block-size: 8lh = "stop growing after 8 lines, then show a scrollbar".
  4. It works on a one-line <input> too: it grows sideways. ch is a unit roughly "one character wide".

3 The picture version

😓 Before: on every single key press

  1. ⌨️You type a letter
  2. 👂JS hears it
  3. 🗜️JS squashes the box
  4. 📏JS measures the text
  5. ✏️JS sets the height

😎 After

  1. ⌨️You type
  2. 🎈The box fits its content, like any other element

4 Good to know

🧰

Works on <textarea>, <input> and <select>. Always set a max size so a huge paste doesn't make a giant box.

🪜

Old browsers simply keep the normal fixed size, so it's a safe upgrade.

<textarea>🧱 HTML tag
A text box for many lines of text.Like: a notepad
<input>🧱 HTML tag
A form field. Its type decides what kind: text, email, checkbox, radio...Like: a blank on a paper form
rows⚙️ HTML attribute
How many lines tall a textarea starts.Like: the size of the notepad
value⚙️ HTML attribute
The starting text (or value) of a field.Like: a form that is already filled in
field-sizing🔧 Property
field-sizing: content makes a text box grow and shrink to fit what you type.Like: a balloon that grows as you blow
min-block-size / max-block-size🔧 Property
The smallest and biggest the box can be in height.Like: a lift that only goes between floors 1 and 10
min-inline-size / max-inline-size🔧 Property
The smallest and biggest the box can be in width.Like: a belt with a smallest and biggest hole
overflow🔧 Property
What to do with content too big for its box: visible (spill out), hidden (cut off), auto (scrollbars when needed).Like: a suitcase that is too full
lh📏 Unit
The height of one line of text. 3lh = three lines tall.Like: lines on writing paper
ch📏 Unit
The width of the "0" character. 20ch = about 20 letters wide.Like: counting letters
