Lesson 16 / 17 · ⚖️ text-wrap

Beautiful headlines: no more lonely last words

Headlines often wrap with one sad word alone on the last line. Designers hate it. We used JS libraries that tried width after width to even the lines out. Now it's one CSS line.

Replaces: balance-text.js · manual <br> tags · &nbsp; hacks Uses: text-wrap: balance · text-wrap: pretty ✅ balance: all modern browsers (Baseline 2024) ⚠️ pretty: Chrome/Edge + Safari (others ignore it safely)

1 In plain English

🤔

What are we building?Headlines with even lines

Instead of a long first line and one word on the second, we want two lines of roughly equal length.

👗📏

😓 The old wayTry on every size of shirt

A JS library makes the headline narrower and narrower, checking each time whether it grew an extra line, until it finds the tightest fit. Then it does it all again when you resize the window.

⚖️

😎 The new wayThe browser balances the scales

text-wrap: balance tells the browser "share the words out evenly between the lines". It already knows how wide every word is.

🧐 What this code does, step by step

  1. JS measures how tall the headline is normally (say 2 lines).
  2. It tries a narrower width and measures again. Still 2 lines? Try narrower. 3 lines? Too far, go back a bit.
  3. This "guess halfway" method is called a binary search 🔍. It's like guessing a number from 1 to 100 by always asking "higher or lower?"
  4. The narrowest width that still fits in 2 lines gives the most even lines.
  5. Every measurement makes the browser recalculate the layout, and it all has to re-run on every resize.

🧐 What this code does, step by step

  1. text-wrap: balance = "make the lines about the same length". Great for headlines and short text.
  2. The browser already knows how wide every word is, so it does this while drawing. No measuring, no jump.
  3. text-wrap: pretty is the gentler version for paragraphs: it only fixes a lonely last word (an "orphan").
  4. Browsers that don't know pretty just wrap normally. Nothing breaks.

4 Good to know

📏

balance is limited to short text (Chrome: up to about 6 lines), because balancing a whole essay would be slow. Use it on headings, captions and buttons.

🌍

An easy win for any site: h1, h2, h3 { text-wrap: balance; } and p { text-wrap: pretty; }. This presentation uses exactly that.
