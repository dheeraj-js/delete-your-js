Fade in from nothing, and out again

Animating something that was hidden with display: none used to be impossible in CSS. The animation got skipped. We used timing hacks in JS. Now CSS can animate things appearing and disappearing.

Replaces: requestAnimationFrame hacks · setTimeout · transitionend listeners Uses: @starting-style · transition-behavior: allow-discrete ✅ All modern browsers (Baseline 2024)

1 In plain English

🤔

What are we building?A notification that slides in

Click a button and a message ("toast" 🍞) fades and slides up in the corner. Click again and it fades away.

🎬

😓 The old wayThe actor skips the entrance

When something goes from display: none to visible, the browser puts it straight in its final spot. To make it animate, JS had to show it, wait two frames, then start the animation.

🎭

😎 The new wayTell the actor where to start

@starting-style says "when you first appear, start from HERE" (invisible, a bit lower). The browser then animates to the normal style.

🧐 What this code does, step by step

  1. Showing: remove hidden so it exists on the page. But if we add is-visible straight away, the browser skips the animation.
  2. So we wait with requestAnimationFrame ("do this on the next frame") twice, to be sure the browser has drawn the invisible version first.
  3. Only then do we add is-visible and the fade runs.
  4. Hiding: remove is-visible to start fading, then wait for transitionend ("the animation finished") before setting hidden. Otherwise it vanishes instantly.

🧐 What this code does, step by step

  1. The toast is a popover (Lesson 01), so the button can open and close it with no JS.
  2. :popover-open is the "open" mood 😊: fully visible, in its normal spot.
  3. @starting-style = "on the very first frame after appearing, pretend you look like THIS": invisible and 20px lower. The browser then animates to the open style. That's the job of JS steps 1-4.
  4. display .4s allow-discrete says "when closing, keep me on screen for 0.4s so the fade-out can play". That replaces the transitionend code.
  5. overlay does the same for the top layer 🥞, so it stays on top while fading out.

4 Good to know

🪟

The same trick animates dialogs (Lesson 02) and their backdrop: dialog[open] plus @starting-style.

🆕

It also works for elements just added to the page by JS (like a new item in a list). They animate in automatically.

♿

Be kind: wrap big movements in @media (prefers-reduced-motion: no-preference) for people who get motion sick.

💡 No more "wait two frames" hacks. Tell CSS where the animation starts.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

@starting-style📜 @-rule
The "before" style for an element's first appearance, so it can animate in (e.g. from invisible).Like: where the actor stands before walking on stage
:popover-open😊 Pseudo-class: a "mood"
When a popover is showing.Like: "when the jack-in-the-box is out"
popover⚙️ HTML attribute
Turns an element into a pop-up that starts hidden, shows on the top layer, and closes on Esc or a click outside.Like: a jack-in-the-box
popovertarget⚙️ HTML attribute
On a button: clicking it opens and closes the popover with that id.Like: a remote paired with one TV
hidden⚙️ HTML attribute
Hides the element until the attribute is removed.Like: an invisibility cloak
id⚙️ HTML attribute
A unique name for ONE element. Buttons, labels and links point at it.Like: a house number
opacity🔧 Property
How see-through: 0 = invisible, 1 = solid.Like: a dimmer for glass
translate🔧 Property
Moves an element sideways or up and down without moving anything else. Cheap to animate.Like: sliding a sticker on glass
transition🔧 Property
Animate smoothly when a value changes, instead of jumping.Like: a dimmer switch instead of an on/off switch
s / ms📏 Unit
Seconds and milliseconds, for timings. 1000ms = 1s, so .3s = 300ms.Like: a stopwatch
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
