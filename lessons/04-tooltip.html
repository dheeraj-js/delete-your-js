Lesson 04 / 17 · 💬 Anchor positioning

Tooltips that stick to their button

Tie one element to another, like a balloon tied to a wrist. If there's no room above, it flips below by itself. No measuring, no maths, no Popper.js.

Replaces: getBoundingClientRect() · scroll/resize listeners · Popper.js / Floating UI Uses: anchor-name · position-anchor · position-area · position-try 🆕 Chrome/Edge 125+, Safari 26+, Firefox rolling out in 2026 (check caniuse)

1 In plain English

🤔

What are we building?A little speech bubble on hover

Hover or tab to a button and a hint pops up above it. Near the top of the screen? It should go below instead.

📐

😓 The old wayMeasure, calculate, repeat forever

JS asks "where is the button right now?", calculates where the bubble should go in pixels, and has to do it again on every scroll and every resize.

🎈

😎 The new wayTie a balloon to a wrist

Give the button a name (the anchor) and tell the bubble "stick to the top of that". Wherever the button goes, the bubble follows.

⚓ anchor-name: --btn

Step 1: give the button a name, like a name-tag for anchoring.

🎈 position-anchor: --btn

Step 2: tell the bubble which anchor to hold on to.

🧭 position-area: top

Step 3: say which side. Think of a 3×3 grid around the button.

2 Before vs after: hover (or Tab to) the buttons

⚠️

Your browser doesn't support anchor positioning yet, so the green demo won't place its bubble correctly. Try it in Chrome, Edge or Safari 26+.

🔁re-runs on every scroll

🧐 What this code does, step by step

  1. getBoundingClientRect() asks the browser: "where exactly is this button on screen right now?" (x, y, width, height).
  2. JS calculates a position above the button. If that's off the top of the screen, it goes below instead.
  3. JS writes the result as pixel numbers: top: 123px; left: 456px.
  4. It needs 6 listeners: mouse in/out, keyboard focus in/out, and scroll and resize, because the moment the page moves, the numbers are wrong.
  5. Real projects usually download a library (Popper.js / Floating UI) to do this properly.
😎

AFTER · CSS

Anchor positioning

I'm tied to the button with CSS 🎈

🔄flips by itself

🧐 What this code does, step by step

  1. anchor-name: --tip-btn gives the button a name to hold on to ⚓. The -- just means "a name I made up".
  2. position-anchor: --tip-btn says: "bubble, hold on to that button" 🎈.
  3. position-area: top says which side. Imagine a 3×3 grid around the button; we pick the top middle square.
  4. position-try-fallbacks: flip-block says: "if there's no room on top, try the bottom". Scroll so the button is near the top of your screen to see it.
  5. :hover and :focus-visible are moods 😊. The + means "the thing right next to it". So: "when the button is hovered or focused, show the bubble next to it".

4 Good to know

🤝

Best combo: anchor positioning + popover (Lesson 01). Popover does the open/close, anchor does the placing. That's a complete dropdown with zero JS.

🗺️

position-area values you can try: top, bottom, left, right, top left, bottom span-right...

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

anchor-name🔧 Property
Gives an element a name so other elements can be placed next to it.Like: dropping a pin on a map
position-anchor🔧 Property
Says which anchor (by name) this element should stick to.Like: "follow that pin"
position-area🔧 Property
Places an element around its anchor using a simple 3×3 grid, e.g. top or bottom center.Like: "sit in the seat above"
position-try-fallbacks🔧 Property
Backup places to try if there's no room, e.g. flip-block moves it to the other side.Like: "if that seat is taken, sit on the other side"
:hover😊 Pseudo-class: a "mood"
When the mouse pointer is over the element.Like: "when someone points at me"
:focus-visible😊 Pseudo-class: a "mood"
When the element is focused by keyboard (the Tab key), so you can show a focus ring only when it helps.Like: a spotlight for keyboard users
:is()😊 Pseudo-class: a "mood"
A shortcut for a list: :is(:hover, :focus-visible) means "hovered OR focused".Like: "any of these"
aria-describedby⚙️ HTML attribute
Points to another element (by id) that describes this one. Screen readers read it too.Like: a footnote
role⚙️ HTML attribute
Tells screen readers what something is (e.g. dialog, tooltip) when the tag doesn't say it already.Like: a job-title badge
position🔧 Property
How a box is placed: static (normal), relative, absolute (exact spot inside a positioned parent), fixed (stuck to the screen), sticky.Like: pinning a note to the board
opacity🔧 Property
How see-through: 0 = invisible, 1 = solid.Like: a dimmer for glass
transition🔧 Property
Animate smoothly when a value changes, instead of jumping.Like: a dimmer switch instead of an on/off switch
margin🔧 Property
Space OUTSIDE the border, pushing other things away.Like: personal space
s / ms📏 Unit
Seconds and milliseconds, for timings. 1000ms = 1s, so .3s = 300ms.Like: a stopwatch
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
<span>🧱 HTML tag
A plain wrapper for a bit of text inside a line.Like: a highlighter pen
