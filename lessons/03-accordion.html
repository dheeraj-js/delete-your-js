Accordions that only open one at a time

The classic FAQ list: click a question, the answer slides open, and the other answers close. We used to measure heights with JavaScript. Now HTML and CSS do all of it.

Replaces: click listeners · "close the others" loops · height measuring Uses: <details name> · ::details-content · interpolate-size ✅ Accordion: all browsers ⚠️ Smooth animation: Chrome/Edge (others just open instantly)

1 In plain English

🤔

What are we building?A list of questions that open and close

Only one answer can be open at a time, like a group of drawers where opening one closes the others.

📏

😓 The old wayMeasure every drawer with a tape measure

CSS couldn't animate to "whatever height the content is" (height: auto). So JS measured the content's height in pixels and set it by hand, every time.

🗄️

😎 The new wayBuy drawers that are already linked

<details> opens and closes by itself. Give several the same name and only one can be open. CSS can now animate to auto height too.

🧐 What this code does, step by step

  1. Each answer panel starts at height: 0, so it's invisible.
  2. When a question is clicked, JS loops over every question and closes them all.
  3. Then JS measures how tall the answer really is (scrollHeight) and sets that exact pixel height, so CSS can animate from 0 to that number.
  4. JS also flips aria-expanded by hand for screen readers.
  5. Weak spot: if the text changes size (for example when the window is resized), the saved pixel height is now wrong.

Why only one open at a time?

Because they all share name="faq". That's the whole trick.

0lines of JavaScript
1attribute for "one at a time"
🔍Ctrl+F finds hidden answers

🧐 What this code does, step by step

  1. <details> is a drawer. <summary> is its handle. Click the handle and it opens. It's keyboard and screen-reader friendly.
  2. Every drawer has name="faq". Drawers with the same name are a group, so opening one closes the others.
  3. ::details-content is the hidden part of the drawer. We say "0 tall when closed, auto tall when open".
  4. interpolate-size: allow-keywords is the magic line: it lets CSS animate to auto, the thing JS used to measure for us.
  5. Bonus: press Ctrl+F and search for "brain". The browser opens the right drawer for you. Hand-made accordions can't do that.

4 Good to know

🪜

Progressive enhancement in action: in browsers without interpolate-size, the accordion still works perfectly. It just opens instantly instead of sliding.

📂

Want one open when the page loads? Add the open attribute: <details name="faq" open>.

🧠

interpolate-size can go on :root to let every element on your site animate to auto.

💡 The same "name" = only one open. The browser does the bookkeeping.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

<details>🧱 HTML tag
A box that opens and closes by itself when you click its summary. No JS needed.Like: a drawer
<summary>🧱 HTML tag
The always-visible, clickable heading of a <details>.Like: the drawer handle
name⚙️ HTML attribute
A group name. On <details>: the same name means only one can be open at a time. On form fields: the label used when the form is sent.Like: a team name
aria-expanded⚙️ HTML attribute
Tells screen readers whether the thing this button controls is open (true) or closed (false).Like: an OPEN / CLOSED sign on a shop
::details-content👻 Pseudo-element: a "ghost" part
The part of a <details> that hides and shows. Style it to animate the opening.Like: the inside of a drawer
interpolate-size🔧 Property
interpolate-size: allow-keywords lets the browser animate to and from auto sizes, like height: auto.Like: a dimmer that works for "however tall it needs"
height🔧 Property
How tall the box is. auto = as tall as its content needs.Like: the height of a shelf
block-size🔧 Property
The same as height in English pages (it follows the writing direction).Like: height, said a smarter way
overflow🔧 Property
What to do with content too big for its box: visible (spill out), hidden (cut off), auto (scrollbars when needed).Like: a suitcase that is too full
transition🔧 Property
Animate smoothly when a value changes, instead of jumping.Like: a dimmer switch instead of an on/off switch
list-style🔧 Property
The bullet points of a list. none removes them (and removes the ▶ triangle on a summary).Like: the dots on a shopping list
display🔧 Property
How a box behaves: block (own line), inline (inside text), flex or grid (arranges its children), none (hidden).Like: choosing furniture layout for a room
s / ms📏 Unit
Seconds and milliseconds, for timings. 1000ms = 1s, so .3s = 300ms.Like: a stopwatch
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
<p>🧱 HTML tag
A paragraph of text.Like: a paragraph in a book
