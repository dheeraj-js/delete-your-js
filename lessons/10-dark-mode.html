Lesson 10 / 17 · 🌙 light-dark()

Dark mode with one colour function

Write each colour once, as a pair: "this in light mode, that in dark mode". Add a toggle made from a checkbox and :has(), and you've got a theme switch with no JavaScript.

Replaces: theme-toggle JS · duplicated .dark { } CSS for every colour Uses: color-scheme · light-dark() · :has() ✅ All modern browsers (Baseline 2024)

1 In plain English

🤔

What are we building?A light / dark switch

Flip it and the card changes to dark colours. Flip it back and it's light again.

👔👕

😓 The old wayTwo separate wardrobes

Every colour was written twice: once normally, and again inside a .dark section. JS swapped the .dark sticker on and off.

🧥

😎 The new wayA reversible jacket

light-dark(white, black) is one colour with two sides. The page says which side to wear with color-scheme.

light-dark(#fff, #1b1b2f)
background: white in light, navy in dark
light-dark(#222, #eee)
text: dark in light, light in dark

🧐 What this code does, step by step

  1. color-scheme tells the browser which side of the jacket to wear: light or dark.
  2. :has(.new-switch:checked) (Lesson 08!) = "if the switch inside is ticked, use dark". The switch is just a checkbox with some styling.
  3. light-dark(A, B) = "use A in light mode, B in dark mode". Each colour is written once.
  4. The label text lives in ::after 👻, so CSS can change it too.
  5. Bonus: color-scheme: light dark on :root makes the site follow the user's phone or computer setting automatically.

4 Good to know

💾

Honest limit: CSS can't remember the choice for next time. If the user picks dark and reloads, it resets. Saving the choice (localStorage or a cookie) is still a small, real JS job.

🖥️

Often you don't need a toggle at all: :root { color-scheme: light dark; } follows the OS setting, and form controls and scrollbars change too.

🎨

Works great with CSS variables: --surface: light-dark(#fff, #111); once, then use var(--surface) everywhere.
