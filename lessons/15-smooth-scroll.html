Lesson 15 / 17 · 🛷 scroll-behavior + scroll-margin

Smooth scrolling that doesn't hide under the header

Click "Contact" in the menu and the page glides to that section. The title lands just below the sticky header, not hidden behind it. Two CSS lines, and a bonus highlight.

Replaces: click listeners · preventDefault · offsetTop maths · scrollTo() Uses: scroll-behavior: smooth · scroll-margin-top · :target ✅ All modern browsers

1 In plain English

🤔

What are we building?A menu that glides to sections

A one-page site with a sticky top menu: Home, About, Contact. Click one and it glides there.

🚖

😓 The old wayA taxi driver doing maths

JS stops the normal jump, works out where the section is minus the header height, then drives there smoothly with scrollTo().

🛷

😎 The new wayA sledge with a parking space

scroll-behavior: smooth makes every jump a glide. scroll-margin-top gives each section a "leave 60px of room above me" parking space.

🧐 What this code does, step by step

  1. Normally, clicking href="#contact" jumps instantly to the element with id="contact". JS stops that with preventDefault().
  2. JS finds the section and reads its position from the top (offsetTop).
  3. It subtracts the header height (60px, written by hand; if the header changes, this breaks).
  4. It calls scrollTo() with smooth to glide there.
  5. Side effect: the URL no longer changes to #contact, so you can't share or bookmark the section.

🧐 What this code does, step by step

  1. The links are plain HTML anchor links (href="#new-contact"). They already jump to the section with that id.
  2. scroll-behavior: smooth turns every jump in that scroll area into a glide.
  3. scroll-margin-top: 60px = "when you scroll to me, leave 60px free above me", so the title isn't hidden.
  4. :target is the mood 😊 "I'm the section in the URL right now". We use it to flash yellow when you arrive.
  5. Because it's a real link, the URL updates, the back button works, and you can share the link.
ℹ️

In this demo the whole page may scroll a little too, so the section comes into view. On a real one-page site the page is the scroll area, so that's exactly what you want.

4 Good to know

🌍

Put html { scroll-behavior: smooth; } on your site and every "#" link glides. This whole presentation does that.

📏

Tip: use a CSS variable for the header height (--header-h) and reuse it in scroll-margin-top, so they never get out of sync.

💡 Use real links. Add a glide and a parking space. Delete the scroll maths.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

scroll-behavior🔧 Property
scroll-behavior: smooth makes jumps glide instead of teleport.Like: a slide instead of a trapdoor
scroll-margin-top🔧 Property
Leaves a gap above an element when you jump to it, so a sticky header doesn't cover it.Like: stopping one step before the edge
:target😊 Pseudo-class: a "mood"
The element whose id is in the address bar (e.g. page#faq), the one you just jumped to.Like: "you are here" on a map
@keyframes📜 @-rule
A named animation: the steps from start (from / 0%) to end (to / 100%).Like: the pages of a flip-book
animation🔧 Property
Plays a @keyframes animation: its name, how long, how many times.Like: pressing play on a flip-book
@media📜 @-rule
Rules that only apply in some conditions, e.g. on small screens or when the user asks for less motion.Like: "only when it's raining, take an umbrella"
prefers-reduced-motion🎚️ Value
A device setting for "less animation, please". Check it with @media (prefers-reduced-motion: reduce).Like: a "please don't shake the boat" sign
background🔧 Property
The colour or picture behind the element.Like: wallpaper
href⚙️ HTML attribute
Where a link goes. href="#faq" jumps to the element with id faq.Like: the address on a signpost
id⚙️ HTML attribute
A unique name for ONE element. Buttons, labels and links point at it.Like: a house number
s / ms📏 Unit
Seconds and milliseconds, for timings. 1000ms = 1s, so .3s = 300ms.Like: a stopwatch
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<nav>🧱 HTML tag
A group of main links for getting around.Like: a signpost at a crossroads
<a>🧱 HTML tag
A link. Its href says where it goes.Like: a signpost
<section>🧱 HTML tag
A themed part of a page, usually with a heading.Like: a chapter
