Lesson 08 / 17 · 👨‍👧 :has()

The parent selector: style a box by what's inside it

For 25 years developers asked for one thing: "let CSS style a parent based on its child." Now we have it. It might be the most powerful CSS feature in years.

Replaces: change listeners · closest() · classList.toggle on parents Uses: :has() ✅ All modern browsers (Baseline 2023)

1 In plain English

🤔

What are we building?A to-do list + a "Sign up" button

Tick a task and its whole card turns green. The Sign up button stays greyed out until you tick "I agree".

🧗

😓 The old wayJS climbs up the family tree

CSS could only look down (parent to child). To style the card when the checkbox inside it changes, JS had to climb up from the checkbox to the card and put a sticker on it.

🔭

😎 The new wayThe parent can look inside itself

.card:has(input:checked) reads like English: "a card that HAS a ticked checkbox inside it".

2 Before vs after: tick the boxes

😓

BEFORE · JavaScript

Climb up and add stickers

10lines of JavaScript
4event listeners
🧗climbing the DOM

🧐 What this code does, step by step

  1. JS finds every checkbox and listens for change (ticked or unticked).
  2. When one changes, closest('.old-task') climbs up the family tree 🧗 to find the card it lives in.
  3. JS puts the is-done sticker on the card (or takes it off). CSS styles the sticker.
  4. A separate listener switches the Sign up button on or off when "I agree" changes.
😎

AFTER · CSS

:has() looks inside

0lines of JavaScript
2CSS rules
🔭reads like English

🧐 What this code does, step by step

  1. Read :has() as the word "has". .new-task:has(input:checked) = "a task that has a ticked input inside it".
  2. :checked is a mood 😊 meaning "ticked". CSS always knows it, so nobody needs to tell it.
  3. Rule 2: "a form that has an agree box that is NOT ticked: dim its button". :not() means "not".
  4. required on the checkbox means the browser won't submit the form until it's ticked, even if someone clicks the dimmed button.
  5. No listeners and no climbing. When a box changes, the browser re-checks the rules instantly.

3 The picture version

😓 Before

  1. ☑️You tick a box
  2. 👂JS hears "change"
  3. 🧗JS climbs up to the card
  4. 🏷️JS adds "is-done"
  5. 🎨CSS colours the card

😎 After

  1. ☑️You tick a box
  2. 🔭CSS: "this card HAS a ticked box"
  3. 🎨Card turns green

4 More :has() superpowers

🖼️

.card:has(img): cards with a picture get a different layout from cards without one.

🚫

html:has(dialog[open]): stop the page scrolling when a modal is open (Lesson 02).

🎨

body:has(#dark:checked): a whole-site theme switch with no JS (Lesson 10).

❗

form:has(:user-invalid): highlight the whole form if any field is wrong (Lesson 07).

🤫

Remember the CSS switch in Lesson 00? That was :has(#css-on:not(:checked)).

💡 If you're writing JS just to put a class on a parent, :has() can probably do it.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

:has()😊 Pseudo-class: a "mood"
"Has something inside that matches". Lets a parent change because of its child. The famous "parent selector".Like: "any box that has a cat in it"
:checked😊 Pseudo-class: a "mood"
When a checkbox or radio button is ticked, or a select option is chosen.Like: a light switch in the ON position
:not()😊 Pseudo-class: a "mood"
"Is NOT ...". :not(:checked) means "not ticked".Like: "everyone except..."
<form>🧱 HTML tag
A group of fields that can be sent together.Like: a paper form
<label>🧱 HTML tag
The name of a form field. Clicking it focuses (or ticks) the field.Like: the name sticker on a letterbox
<input>🧱 HTML tag
A form field. Its type decides what kind: text, email, checkbox, radio...Like: a blank on a paper form
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
type⚙️ HTML attribute
The kind of input: text, email, checkbox, radio...Like: choosing the shape of a blank on a form
required⚙️ HTML attribute
The field must be filled in before the form can be sent.Like: a box marked with a red star
disabled⚙️ HTML attribute
Switches the button or field off: greyed out and unclickable.Like: a lift button with tape over it
background🔧 Property
The colour or picture behind the element.Like: wallpaper
border-color🔧 Property
Just the colour of the border.Like: painting the frame
text-decoration🔧 Property
Lines on text: underline, or line-through (crossed out).Like: underlining with a pen
opacity🔧 Property
How see-through: 0 = invisible, 1 = solid.Like: a dimmer for glass
cursor🔧 Property
The shape of the mouse pointer: pointer (a hand), not-allowed (a no-entry sign).Like: a sign on the door
