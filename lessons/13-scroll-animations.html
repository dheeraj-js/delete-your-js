Lesson 13 / 17 · 📜 Scroll-driven animations

Animations controlled by scrolling

A reading progress bar. Cards that fade in as they scroll into view. We used to listen to scroll events hundreds of times a second. Now the scrollbar itself can drive a CSS animation. (Look at the top of this page: that green bar is pure CSS.)

Replaces: scroll listeners · IntersectionObserver · GSAP ScrollTrigger / AOS libraries Uses: animation-timeline: scroll() · view() · animation-range 🆕 Chrome/Edge, Safari 26+. Firefox: still coming, check caniuse

1 In plain English

🤔

What are we building?A progress bar + fade-in cards

As you scroll the article, a bar at the top fills up, and each card gently fades in as it comes into view.

⏱️

😓 The old wayAnimation runs on a stopwatch

Normal CSS animations run on time ("take 1 second"). To link them to scrolling, JS had to watch the scroll position constantly and update styles by hand.

📼

😎 The new wayScrolling = the play head

Imagine a video where you drag the play head. animation-timeline: scroll() swaps the stopwatch for the scrollbar: scroll down = play forward, scroll up = rewind.

2 Before vs after: scroll inside each box

⚠️

Your browser doesn't support scroll-driven animations yet. The green bar will just look full and the cards visible, which is a safe fallback. Try Chrome, Edge or Safari 26+.

🧐 What this code does, step by step

  1. Progress bar: on every scroll, JS works out "how far down am I?" as a percentage: scrollTop ÷ (total height − visible height).
  2. It writes that into the bar's width. This can run 60+ times per second while you scroll.
  3. Reveal: an IntersectionObserver is a lookout 🔭 that says "this card is now 30% visible".
  4. JS then adds the is-shown sticker and a CSS transition fades the card in.

🧐 What this code does, step by step

  1. @keyframes is a normal CSS animation: "go from THIS to THAT" (bar from 0% to 100% wide).
  2. Normally it would play over time. animation-timeline: scroll() says "use the scrollbar as the play head instead": top = start, bottom = end.
  3. view() is a different play head: "how far through the visible area is THIS card?". Each card gets its own.
  4. animation-range: entry 0% cover 35% = "play from when the card starts entering until it's 35% of the way through".
  5. No listeners. The browser runs it smoothly, even when JS is busy.

4 Good to know

👆

This site dogfoods it: the coloured bar at the very top of this page is animation-timeline: scroll(root). root means "the whole page's scrollbar".

🪜

Unsupported browsers ignore animation-timeline, so the animation finishes instantly: bar full, cards visible. A safe fallback.

♿

Big parallax effects can make people feel sick. Put them inside @media (prefers-reduced-motion: no-preference) { ... }.

💡 Don't listen to scroll events. Let the scrollbar play the animation.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

@keyframes📜 @-rule
A named animation: the steps from start (from / 0%) to end (to / 100%).Like: the pages of a flip-book
animation🔧 Property
Plays a @keyframes animation: its name, how long, how many times.Like: pressing play on a flip-book
animation-timeline🔧 Property
What drives the animation. Normally the clock. scroll() = the scrollbar, view() = the element moving on screen.Like: swapping the clock for a scroll wheel
scroll()🧮 Function
An animation timeline driven by the scrollbar: 0% at the top, 100% at the bottom.Like: a flip-book you turn by scrolling
view()🧮 Function
An animation timeline driven by the element moving through the screen as you scroll.Like: a door that opens as you walk up to it
animation-range🔧 Property
Which part of the scroll the animation plays in, e.g. entry 0% to cover 40%.Like: "only play between these two lamp posts"
opacity🔧 Property
How see-through: 0 = invisible, 1 = solid.Like: a dimmer for glass
translate🔧 Property
Moves an element sideways or up and down without moving anything else. Cheap to animate.Like: sliding a sticker on glass
scale🔧 Property
Makes an element bigger or smaller. 1 = normal size, 2 = double.Like: a zoom lens
transform-origin🔧 Property
The pivot point for scale and rotate, e.g. left or center.Like: the pin in a spinning wheel
transition🔧 Property
Animate smoothly when a value changes, instead of jumping.Like: a dimmer switch instead of an on/off switch
s / ms📏 Unit
Seconds and milliseconds, for timings. 1000ms = 1s, so .3s = 300ms.Like: a stopwatch
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
