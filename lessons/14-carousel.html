Lesson 14 / 17 · 🎠 Scroll snap + scroll buttons

Carousels without a slider library

Swipe on phones, snap neatly to each slide, arrow buttons and dots. We used to download a slider library for this. The basics (swipe + snap) work in every browser today, and arrows and dots are arriving now.

Replaces: Slick · Swiper · Owl Carousel · touch event code Uses: scroll-snap · ::scroll-button() · ::scroll-marker ✅ Swipe + snap: all browsers ⚠️ Arrows + dots: Chrome/Edge 135+ (others still swipe fine)

1 In plain English

🤔

What are we building?A slideshow of pictures

One slide at a time. Swipe or press arrows to move. Dots show where you are.

🚂

😓 The old wayPush the train by hand

All slides sit in a long row, like train carriages. JS keeps a slide number and pushes the whole train sideways with translateX. Swiping on phones needs even more code.

🧲

😎 The new wayMagnets on the rails

Make the row scrollable and add magnets (scroll-snap), so each slide clicks into place. Phones can swipe it for free. New CSS even creates the arrows and dots for you.

Your browser can't draw CSS scroll buttons and dots yet. The green carousel still scrolls and snaps (trackpad, shift+wheel, or swipe), just without arrows. That's progressive enhancement 🪜.

🧐 What this code does, step by step

  1. All slides sit in one long row (display: flex), each one full width. A "window" with overflow: hidden shows only one.
  2. JS remembers a number: which slide we're on (index).
  3. Arrow clicked: add or subtract 1. The % maths makes it wrap from the last slide back to the first.
  4. JS pushes the whole row sideways: slide 2 = translateX(-100%), slide 3 = -200%...
  5. JS moves the "active" sticker to the right dot. Swiping on a phone still doesn't work.

🧐 What this code does, step by step

  1. The slides sit in a row you can scroll sideways (overflow-x: auto). Phones can swipe it, and trackpads and keyboards can scroll it. No code.
  2. scroll-snap-type: x mandatory adds magnets 🧲: when you let go, it always settles on a slide. scroll-snap-align: center says where each magnet is.
  3. ::scroll-button(left/right) asks the browser to create arrow buttons. They scroll by one slide and grey out at the ends.
  4. scroll-marker-group + ::scroll-marker ask the browser to create the dots. :target-current is the dot for the slide you're on.
  5. The arrows use anchor positioning (Lesson 04) to sit on the carousel's edges.

Ship it today: scroll-snap works everywhere, so every user can swipe. Chrome and Edge users get arrows and dots as a bonus.

📖 Words used on this page 📖

Never written CSS? Here is every CSS and HTML word from the code boxes above, in plain English. The very basics (like px, margin and .name) are in the starter kit in Lesson 00.

scroll-snap-type🔧 Property
Makes a scroll area stop neatly on items. x mandatory = always snap sideways.Like: magnets that pull each slide into place
scroll-snap-align🔧 Property
Which edge of an item snaps into place: start, center or end.Like: where the magnet sits
overflow-x🔧 Property
Overflow for left-to-right only. auto = scroll sideways when needed.Like: a sideways conveyor belt
scroll-behavior🔧 Property
scroll-behavior: smooth makes jumps glide instead of teleport.Like: a slide instead of a trapdoor
scrollbar-width🔧 Property
How thick the scrollbar is: auto, thin or none.Like: a thin or thick handrail
::scroll-button()👻 Pseudo-element: a "ghost" part
Previous and next buttons that the browser makes for a scroll area. ::scroll-button(left) is the left one.Like: the arrows on a lift
:disabled😊 Pseudo-class: a "mood"
When a button or field is switched off and can't be used.Like: a greyed-out lift button
scroll-marker-group🔧 Property
Switches on the row of dots for a carousel, before or after the slides.Like: switching on the page dots
::scroll-marker-group👻 Pseudo-element: a "ghost" part
The row that holds a carousel's dots.Like: the washing line the dots hang on
::scroll-marker👻 Pseudo-element: a "ghost" part
One dot per slide. Click it to jump to that slide.Like: a bookmark for each slide
:target-current😊 Pseudo-class: a "mood"
In a carousel, the dot (scroll marker) for the slide you can see right now.Like: the lit-up floor number in a lift
display🔧 Property
How a box behaves: block (own line), inline (inside text), flex or grid (arranges its children), none (hidden).Like: choosing furniture layout for a room
grid-auto-flow🔧 Property
Where new grid items go. column = each new item starts a new column (side by side).Like: adding train carriages at the end
grid-auto-columns🔧 Property
How wide each automatic column is. 100% = one slide fills the view.Like: the size of each carriage
gap🔧 Property
The space between items in a flex or grid layout.Like: the gaps between tiles
flex🔧 Property
How an item in a flex row grows or shrinks to share the space.Like: people squeezing up on a bench
justify-content🔧 Property
Spreads children along the row: start, center, space-between...Like: spacing chairs along a table
overflow🔧 Property
What to do with content too big for its box: visible (spill out), hidden (cut off), auto (scrollbars when needed).Like: a suitcase that is too full
list-style🔧 Property
The bullet points of a list. none removes them (and removes the ▶ triangle on a summary).Like: the dots on a shopping list
margin🔧 Property
Space OUTSIDE the border, pushing other things away.Like: personal space
padding🔧 Property
Space INSIDE the border, between the edge and the content.Like: bubble wrap inside a box
anchor-name🔧 Property
Gives an element a name so other elements can be placed next to it.Like: dropping a pin on a map
position-anchor🔧 Property
Says which anchor (by name) this element should stick to.Like: "follow that pin"
position-area🔧 Property
Places an element around its anchor using a simple 3×3 grid, e.g. top or bottom center.Like: "sit in the seat above"
position🔧 Property
How a box is placed: static (normal), relative, absolute (exact spot inside a positioned parent), fixed (stuck to the screen), sticky.Like: pinning a note to the board
width / height🔧 Property
How wide and how tall the box is.Like: the size of a picture frame
border🔧 Property
A line around the box: thickness, style and colour, e.g. 1px solid grey.Like: a picture frame
border-radius🔧 Property
Rounds the corners. Bigger number = rounder.Like: sanding the corners of a table
background🔧 Property
The colour or picture behind the element.Like: wallpaper
color🔧 Property
The text colour.Like: the ink in the pen
cursor🔧 Property
The shape of the mouse pointer: pointer (a hand), not-allowed (a no-entry sign).Like: a sign on the door
opacity🔧 Property
How see-through: 0 = invisible, 1 = solid.Like: a dimmer for glass
content🔧 Property
The text or symbol a ::before or ::after ghost shows.Like: what the ghost says
translate🔧 Property
Moves an element sideways or up and down without moving anything else. Cheap to animate.Like: sliding a sticker on glass
scale🔧 Property
Makes an element bigger or smaller. 1 = normal size, 2 = double.Like: a zoom lens
transition🔧 Property
Animate smoothly when a value changes, instead of jumping.Like: a dimmer switch instead of an on/off switch
rem📏 Unit
Relative to the page's base text size (usually 16px). 2rem = twice that. Grows if the user picks bigger text.Like: "two handfuls": depends on the hand
px📏 Unit
Pixels: one dot on the screen. A fixed size.Like: centimetres on a ruler
<div>🧱 HTML tag
A plain box with no special meaning, used to group things.Like: a cardboard box
<button>🧱 HTML tag
A button you can click or press with the keyboard.Like: a doorbell
<ul> / <li>🧱 HTML tag
A list (ul) and each item in it (li).Like: a shopping list and its lines
