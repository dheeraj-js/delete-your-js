Delete your JS

17 everyday things we used to build with JavaScript that the browser can now do with a few lines of HTML and CSS. Every example has a live before and after you can click. Not "no JavaScript": HTML and CSS for every job they can do, JavaScript for the rest.

🎯 What you'll learn today, in 30 seconds

😓1 · The problem

Websites use JavaScript for jobs the browser can already do

  • 650 KB of JavaScript on a typical phone page
  • 1.9 s the phone is too busy to answer a tap
  • Only 48% of phone sites pass Google's speed scores

Web Almanac 2025

💡2 · The idea

Let HTML & CSS do every job they already can

Menus, pop-ups, accordions, tooltips, carousels, dark mode, form checks: the browser has them built in now.

  • 📦 Less to download
  • 👷 Less for the phone to run
  • ⭐ Better Web Vitals
  • ♿ Accessible for free
🧠3 · Keep JavaScript for

The jobs only a brain can do

  • 💾 Saving & remembering
  • 🌐 Talking to servers
  • 🧮 Real logic & maths
  • ⏱️ Timers & auto-play
  • 📊 Analytics
  • 🎮 Truly interactive apps

🧭 The one question to take home: "Can HTML or CSS already do this?" If yes, you don't need the JavaScript.

"Use the least powerful language suitable for the job."

📜 W3C · The Rule of Least Power · Tim Berners-Lee, 2006

"Make your page work with HTML first."

🏛️ GOV.UK Service Manual · how every UK government service is built
